Настройка Firebase для Todo App

1. Включите Google Authentication:

Firebase Console → Authentication → Sign-in method → Google → Enable

Добавьте Project support email

2. Добавьте авторизованные домены:

Authentication → Settings → Authorized domains → Add domain

Добавьте: azizsabitov7-alt.github.io

Также добавьте: localhost для разработки

3. Настройте правила Firestore:

Firestore Database → Rules → Вставьте:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId} { allow read, write: if request.auth != null && request.auth.uid == userId; } match /users/{userId}/tasks/{taskId} { allow read, write: if request.auth != null && request.auth.uid == userId; } } }

Нажмите "Publish"
